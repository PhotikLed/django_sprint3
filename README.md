# Блогикум. Часть 2: публикации

Стартовый репозиторий для второй части проекта «Блогикум».
В папке `blogicum/` уже подготовлено приложение по заданию первой части:
главная страница, страницы публикаций и категорий, страницы «О проекте»
и «Наши правила», общие шаблоны и статика.
Данные трёх публикаций пока хранятся в списке `posts` в файле
`blogicum/blog/views.py`.

Во второй части нужно перейти к базе данных. Требования к моделям,
панели администратора и отображению публикаций приведены в уроке.

## Структура

```text
ap-django2/
├── blogicum/
│   ├── blog/              # Приложение публикаций
│   ├── pages/             # Статические страницы
│   ├── blogicum/          # Настройки и маршруты проекта
│   ├── static/            # CSS и изображения
│   ├── templates/         # Работающие шаблоны первой части
│   └── manage.py
├── templates/             # Новые шаблоны для второй части
├── tests/                 # Тесты второй части
├── db.json                # Фикстуры для будущих моделей
├── pytest.ini
└── requirements.txt
```

В уроке локальная папка репозитория называется `django_sprint3`.
Можно задать это имя при клонировании или переименовать распакованную
папку `ap-django2`. Все команды ниже выполняются из корня репозитория,
где находится `requirements.txt`.

## Запуск

Используйте Python 3.11. Проект подготовлен для Django 5.2.19.
Зависимости для тестирования обновлены под Django 5.2; `pytz` указан
явно, поскольку его используют исходные тесты задания.

```bash
python -m venv venv
```

Активируйте окружение в Linux/macOS:

```bash
source venv/bin/activate
```

Или в Windows PowerShell:

```powershell
.\venv\Scripts\Activate.ps1
```

Установите зависимости и запустите проект:

```bash
python -m pip install -r requirements.txt
python blogicum/manage.py migrate
python blogicum/manage.py runserver
```

Откройте <http://127.0.0.1:8000/>. Для просмотра публикаций первой части
загружать `db.json` не нужно: пока они берутся из списка `posts`.

## С чего начать вторую часть

1. Откройте `blogicum/blog/views.py`: здесь находится список `posts`,
   который нужно удалить по заданию. После удаления замените обращения
   к этому списку запросами к базе данных, когда создадите модели.
2. Выполните требования урока к моделям, миграциям и панели администратора.
   Модели второй части и их регистрация в админке пока не реализованы.
3. По инструкции урока замените шаблоны в `blogicum/templates/` новыми
   шаблонами из корневой папки `templates/`. Они рассчитаны на объекты моделей.
4. Когда модели и миграции будут готовы, выполните миграции и загрузите
   фикстуры из корня репозитория:

   ```bash
   python blogicum/manage.py makemigrations
   python blogicum/manage.py migrate
   python blogicum/manage.py loaddata db.json
   ```

## Проверка задания

```bash
pytest
```

В `tests/` находятся исходные тесты второй части. В стартовом состоянии
они ещё не проходят: сначала нужно реализовать модели `Post`, `Category`
и `Location`. До этого pytest завершится ошибкой при импорте моделей.

Проверить базовую конфигурацию прекода можно отдельно:

```bash
python blogicum/manage.py check
```
